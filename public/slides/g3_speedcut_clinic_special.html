Original Question

양수 $k$에 대하여 함수 $f(x) = kx(x-2)(x-3)$이다. 곡선 $y=f(x)$와 $x$축이 원점 $\text{O}$와 두 점 $\text{P, Q}$ $(\text{OP} < \text{OQ})$에서 만난다.

곡선 $y=f(x)$와 선분 $\text{OP}$로 둘러싸인 영역을 $A$, 곡선 $y=f(x)$와 선분 $\text{PQ}$로 둘러싸인 영역을 $B$라 하자.

$(A\text{의 넓이}) - (B\text{의 넓이}) = 3$일 때, $k$의 값은?

함수 $y=f(x)$와 넓이 $A, B$ 시각화

문항 01 [원문 해설]  정석 vs 숏컷 풀이 비교

학생들의 돌아가는 정석 풀이

영역 분할 후 개별 넓이 적분

1. 근 $x=0, 2, 3$ 확인 및 넓이 식 세우기:
   $A = \int_0^2 f(x)dx$,  $B = -\int_2^3 f(x)dx$

2. 개별 4차식 적분 계산:
   $f(x) = k(x^3 - 5x^2 + 6x)$
   $A = k\left[\frac{1}{4}x^4 - \frac{5}{3}x^3 + 3x^2\right]_0^2 = k\left(4 - \frac{40}{3} + 12\right) = \frac{8}{3}k$

3. $B$ 영역 계산 후 $A - B = 3$ 방정식 풀이:
   $B = -k\left[\frac{1}{4}x^4 - \frac{5}{3}x^3 + 3x^2\right]_2^3 = \frac{5}{12}k \implies \frac{8}{3}k - \frac{5}{12}k = 3$

분수 통분 및 이중 적분 계산으로 3~4분 소요 & 계산 실수 유발
강사의 숏컷 풀이

"넓이의 차이는 정적분 그 자체다!"

핵심 개념: $x$축 위 넓이 $A$와 아래 넓이 $B$의 차이 $A-B$는 구간을 나누지 않고 $0$부터 $3$까지의 한 번의 정적분과 완전히 동일합니다!

한 줄 식 세우기:
$$\int_0^3 kx(x-2)(x-3)dx = 3$$

원샷 계산:
$$k\left[\frac{1}{4}x^4 - \frac{5}{3}x^3 + 3x^2\right]_0^3 = k\left(\frac{81}{4} - 45 + 27\right) = \frac{9}{4}k = 3$$ $$\therefore k = \frac{4}{3}$$

계산량 70% 감소, 단 40초 만에 정답 도출!

함정 포인트 (Trap Point)

영역 $B$가 $x$축 아래에 위치한다는 기하학적 사실에 매몰되어, 무의식적으로 절댓값을 씌워 양수로 만든 후 다시 빼는 불필요한 이중 작업을 수행하는 습관.

  • $A = \int_0^2 f(x)dx$ (양수)
  • $B = -\int_2^3 f(x)dx$ (넓이로 환산)
  • $A - B = \int_0^2 f(x)dx - \left(-\int_2^3 f(x)dx\right) = \int_0^3 f(x)dx$ 임을 식으로 돌아가서 깨닫는 우를 범함.
넓이의 '차' $A-B$는 정적분 정의 $\int_a^b f(x)dx$ 그 자체임을 직관적으로 기억할 것!

문항 02 [원문 해설]  정석 vs 숏컷 풀이 비교

학생들의 돌아가는 정석 풀이

미지수 3개 전개 & 연립방정식

1. $f(x) = x^3 + ax^2 + bx + c$ 로 미지수 3개 세팅

2. 점 $(2,3)$과 $(1,3)$을 지나는 접선 $\rightarrow$ 기울기 $0$
   $f'(2) = 0, \; f(2) = 3$ 조건 대입

3. $(-2, f(-2))$에서의 접선 방정식 작성:
   $y - f(-2) = f'(-2)(x + 2)$

4. 점 $(1,3)$ 대입하여 $a, b, c$ 복잡한 연립방정식 풀이

미지수 3개 세팅 시 대입 및 계산 과정에서 5분 이상 소요
강사의 숏컷 풀이

"수평 접선은 곧바로 차이함수로 세팅하라!"

1. 수평접선 차이함수 세팅:
$(2,3)$과 $(1,3)$을 지나는 접선은 $y=3$ 수평선!
$\implies \mathbf{f(x) - 3 = (x-2)^2(x-\alpha)}$

2. 평균변화율 = 미분계수 조건:
$(-2, f(-2))$와 $(1,3)$을 잇는 평균변화율이 $f'(-2)$와 같음!
$$\frac{3 - f(-2)}{1 - (-2)} = f'(-2)$$

3. 대입 30초 컷:
$f(-2) = 3 - 16(2+\alpha) \implies \frac{16(2+\alpha)}{3} = 4(8+2\alpha) \implies \mathbf{\alpha = -8}$
$f(x) = (x-2)^2(x+8) + 3 \implies \mathbf{f(0) = 35}$

인수분해 차이함수 세팅으로 연립방정식 증발!

함정 포인트 (Trap Point)

'접선이 $(1,3)$을 지나고 $(2,3)$을 지난다'는 문장을 보자마자 기계적으로 $y-f(-2) = f'(-2)(x+2)$라는 긴 접선 방정식부터 써 내려가는 습관.

  • $y$좌표가 $3$으로 동일함($(2,3)$, $(1,3)$)을 간과하고 기울기를 $m$으로 구하려 함.
  • 수평접선의 특수성($y=3$)을 놓치고 일반 접선으로 다루다 풀이가 꼬임.
두 점의 $y$좌표가 같으면 접선은 수평선($y=c$)이며, 이는 최고 조건의 인수분해 힌트다!

문항 03 [원문 해설]  정석 vs 숏컷 풀이 비교

학생들의 돌아가는 정석 풀이

점과 점 사이 거리 공식 대입

1. 좌표 탐색:
   $\text{B}(-2,0), \; \text{C}(2,0) \implies \overline{\text{BC}} = 4$
   교점 $\text{A}(0, \log_a 3)$

2. 두 점 $\text{A, B}$ 사이 점과 점 사이 거리 공식 적용:
   $\sqrt{(0 - (-2))^2 + (\log_a 3 - 0)^2} = 4$

3. 양변 제곱 연산:
   $4 + (\log_a 3)^2 = 16 \implies (\log_a 3)^2 = 12 \implies \log_a 3 = 2\sqrt{3}$

피타고라스 루트 연산으로 불필요한 단계 추가
강사의 숏컷 풀이

"정삼각형 = 특수각 비율 ($1:\sqrt{3}:2$)!"

1. 밑변 길이 측정: $\text{B}(-2,0), \text{C}(2,0) \implies \text{밑변 } = 4$

2. 높이 즉시 도출:
정삼각형 밑변이 $4$이면 높이는 $2\sqrt{3}$!
교점 $\text{A}$가 $y$축 위에 있으므로 $\mathbf{y\text{좌표} = 2\sqrt{3}}$

3. 지수 전환 20초 컷:
$$\log_a 3 = 2\sqrt{3} \implies a^{2\sqrt{3}} = 3 \implies \mathbf{a = 3^{\frac{\sqrt{3}}{6}}}$$

거리 공식 없이 정삼각형 비율 관계로 좌표 다이렉트 획득!

문항 03 [클리닉]  함정 포인트 & 30초 스킵 시그널

함정 포인트 (Trap Point)

$\text{A, B, C}$ 좌표를 다 구해놓고도 '정삼각형의 높이' 성질을 까먹고 기계적으로 점과 점 사이의 거리 공식(루트 계산)으로 진입하는 습관.

  • 대칭축이 $y$축임을 알아챘으면서도 높이 = $y$좌표 관계를 쓰지 않는 계산 낭비.
도형 문제에서 정삼각형, 직각이등변 삼각형이 나오면 피타고라스 공식 전에 특수각 비율부터 써라!

[스피드 체크리스트]

✔ 정삼각형 한 변의 길이 $a \implies$ 높이 $h = \frac{\sqrt{3}}{2}a$ 자동 반사!

학생들의 돌아가는 정석 풀이

로그 식 식조작 & 무리식 유리화

1. 좌표 설정:
   $x_A = \sqrt{\ln(t+1)}, \; x_B = \sqrt{\ln(5t+1)}$

2. 넓이 식 $S(t)$ 작성:
   $S(t) = \frac{1}{2} \cdot 4t \cdot (\sqrt{\ln(5t+1)} - \sqrt{\ln(t+1)})$

3. $\lim_{t\to 0+} \frac{2t(\sqrt{\ln(5t+1)} - \sqrt{\ln(t+1)})}{t\sqrt{t}}$ 의 무리식 켤레 곱하기(유리화) 시도하다 식이 대폭발!

로그 극한 공식 변형 시 분모/분자 차수 혼동으로 낭패
강사의 숏컷 풀이

"초월함수 극한은 테일러/매클로린 1차 근사!"

근사 공식: $t \to 0$ 일 때 $\mathbf{\ln(1+x) \approx x}$

1. 좌표 다이렉트 근사:
$x_A = \sqrt{\ln(t+1)} \mathbf{\approx \sqrt{t}}$
$x_B = \sqrt{\ln(5t+1)} \mathbf{\approx \sqrt{5t}}$

2. 넓이 $S(t)$ 근사 식 30초 작성:
$$S(t) \approx \frac{1}{2} \cdot 4t \cdot (\sqrt{5t} - \sqrt{t}) = 2t\sqrt{t}(\sqrt{5}-1)$$

3. 극한값 직행:
$$\lim_{t\to 0+} \frac{2t\sqrt{t}(\sqrt{5}-1)}{t\sqrt{t}} = \mathbf{2(\sqrt{5}-1)}$$

루트 켤레 유리화 제로, 단 30초 만에 정답!

  • 무리식 뺄셈이 나왔을 때 억지로 켤레식을 분모/분자에 곱하느라 계산량 폭발.
$t\to 0$ 극한에서 초월함수는 근사식을 대입한 후 차수를 비교하는 것이 가장 안전하다!

학생들의 돌아가는 정석 풀이

그래프 케이스 전수조사

1. $x \le 2$ 삼차함수 극대 $( -1, 5 )$, 극소 $( 1, -3 )$ 파악

2. $x > 2$ 이차함수 꼭짓점 축의 위치($b$의 범위) 분류:
   • 축 $\le 2$ 인 경우, 축 $> 2$ 인 경우 나누기

3. $t$값 움직이며 좌극한, 우극한, 함숫값 합이 9인 조합 전수조사하며 표 작성

전수조사 시 7~10분 소요 및 실수 가능성 극대
강사의 숏컷 풀이

"불연속 극한 합 특이점 = 무조건 극값 높이 일치!"

교점 개수의 합이 9가 되는 $k$가 '오직 1개' 존재하려면 이차함수 꼭짓점 최소 높이가 삼차함수의 기존 극값 높이 $y=5$ 또는 $y=-3$과 정확히 일치해야 불연속점이 병합됨!

꼭짓점 높이 식: $9 - \frac{a(b-2)^2}{4}$

Case 1 (높이 5): $a(b-2)^2 = 16 \implies b=3, a=16 \implies a+b = 19$

Case 2 (높이 -3): $a(b-2)^2 = 48 \implies b=3, a=48 \implies \mathbf{a+b = 51}$

극값 높이 병합 조건으로 계산량 1/3 축소!

문항 05 [클리닉]  함정 포인트 & 30초 스킵 시그널

함정 포인트 (Trap Point)

이차함수의 축 위치가 $2$보다 작은 경우와 큰 경우를 세분화하여, 나오지도 않을 불필요한 그래프 개형까지 전부 확인하며 시험 시간을 탕진하는 습관.

  • '실수 $k$의 개수가 1'이라는 유일성 조건이 극값 일치(높이 공유)를 의미한다는 기하적 구조를 보지 못함.
개수 합 조건 문제에서 '유일한 $k$' 조건은 극값 높이의 중복(일치)에서 발생한다!

문항 05 [구조 변형]  실전 응용 문제

Structure Extension

두 자연수 $a, b$에 대하여 함수 $f(x)$가
$x \le 2$일 때 $f(x) = x^3 - 3x + 2$,
$x > 2$일 때 $f(x) = a(x-2)(x-b) + 6$이다.

실수 $t$에 대하여 $y=f(x)$와 $y=t$가 만나는 점의 개수를 $g(t)$라 하자.
$g(k) + \lim_{t\to k-}g(t) + \lim_{t\to k+}g(t) = 9$를 만족시키는 실수 $k$의 개수가 1이 되도록 하는 두 자연수 $a, b$의 순서쌍 $(a, b)$에 대하여 $a+b$의 최댓값을 구하시오.
