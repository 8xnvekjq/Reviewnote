## 왜 다시 만드는가
현재 `dog.png`는 Pillow로 10배 크게 그린 뒤 축소해서 가장자리가 흐리다(반투명 알파 186단계, 색 2,534개).
같은 세계의 곰·비둘기는 네이티브 픽셀(알파 0/255, 평면 색 7개 안팎)이라 나란히 두면 강아지만 뿌옇다.
목표: **곰·비둘기와 같은 제작 파이프라인으로 다시 그린 선명한 픽셀아트 강아지.**
기존 강아지의 정체성(따뜻한 황갈색/크림색 털, 볼터치, 크고 단순한 눈, 둥근 치비 체형)은 유지해서
이미 강아지를 쓰는 학생에게 "다른 펫으로 바뀌었다"는 느낌이 들지 않게 한다.

## 규격 (코드 무변경 조건 — 반드시 지킬 것)
`src/features/pixel-room/pet/assets/dog.png`를 같은 경로에 덮어쓴다.
- **192×192 RGBA 투명 PNG, 셀 32×32, 6행**, 네이티브 픽셀(1px = 1논리px)
- 안티에일리어싱/그라디언트/반투명 없음, 알파는 0 또는 255만. 그림자 없음(코드가 그림).
- 행별 프레임 수는 정확히 아래와 같고, 쓰지 않는 칸은 완전 투명:
  - row 0 **bark** 4프레임 — 짖기(입 벌림·몸 살짝 앞으로), 1회 재생
  - row 1 **walk** 6프레임 — 실내 걷기(90ms/프레임 루프), 발 교대가 보이게
  - row 2 **run** 6프레임 — 실외(마당)에서 쓰는 빠른 걸음, walk보다 보폭·들썩임 크게
  - row 3 **sit transition** 3프레임 — 서 있다가 앉기(약 450ms, 1회)
  - row 4 **idle sit** 4프레임 — 앉아서 숨쉬기/깜빡임 루프
  - row 5 **idle stand** 4프레임 — 서서 숨쉬기/꼬리/깜빡임 루프.
    **row 5 c0은 상점 미리보기 대표 프레임**이라 가장 귀엽고 전신이 잘 보이는 포즈로.
- 크기: 2×2 셀 박스에 32px 캔버스. 몸은 대략 폭 22~26 / 높이 20~24px — 오리·비둘기와 비슷한
  체급, 사람보다 확실히 작게.
- 발끝은 모든 지상 프레임에서 셀 내 **y=30** 기준선에 닿게(비둘기와 동일). 가로 중심 일관,
  의도된 동작 외에는 프레임 간 몸통이 튀지 않게.
- 시점: 곰·비둘기처럼 **정면 약간 왼쪽(front-left 3/4)**. 오른쪽은 코드가 좌우반전한다
  → 비대칭 소품/무늬/글씨 금지(한쪽 귀만 다른 색 등 금지).

## 스타일
- 두꺼운 진갈색 외곽선(곰과 같은 계열), 단순 색면, 2~3단 음영 이하.
- 황갈색 몸 + 크림색 주둥이/배, 작은 접힌 귀, 짧은 다리, 동그란 꼬리, 볼터치(곰과 같은 톤).
- 채도 과하지 않게 — 곰의 갈색, 오리의 노랑, 비둘기의 청회색 옆에서 튀지 않게.
- 팔레트는 곰 팔레트와 최대한 공유(외곽선·볼터치 hex 동일 권장).
