# 까딱 오리 sprite

`duck.png` was generated for Reviewnote with the built-in image generation tool on 2026-09-23, using the user's supplied yellow duck/chick photo as visual reference. It is newly generated project artwork, not a downloaded third-party sprite; no third-party asset pack or license is incorporated. The source photo is not shipped with the app.

The original 1254×1254 RGBA illustration is preserved as `duck-source.png`; the room's `DuckSprite` still crops that source using its measured alpha bounds. Phaser and panel previews use `duck.png`: a native 128×128 transparent sheet, four columns and four rows of 32px cells (idle/head tilt/blink, waddle, peck, hop).

Run `python scripts/pixel-world/pixelate-duck.py` with Pillow to reproduce the native sheet. Each source pose is cropped independently, registered to feet at y=30, reduced without dithering to a fixed ten-color warm palette, given binary alpha and a one-pixel dark inner outline. The script saves before/after and dog comparisons at 4× in `.test-artifacts/pw-bugs-a/`. The chick keeps its small round yellow body, tiny wings and feet, bead eyes and two black head feathers. Phaser loads this native sheet directly without runtime smoothing.

Generation prompt specification: production sprite sheet for a tiny top-down cozy pixel RPG pet; attached photo is character reference only. Transparent PNG, exactly four columns by four rows, square evenly sized cells, no gutters, no text/background/grid/shadow. Each cell represents a 32×32 sprite, nearest-neighbor pixel styling, simple flat palette, clear dark warm-brown outline. Round chubby sunshine-yellow duck/chick, small black eyes, short orange-brown bill, TWO BLACK LITTLE FEATHERS, tiny side wings and short dark feet. No plastic seam/keychain/photorealism/gradients. Consistent approximately 22×22 body inside each cell, slight front-left view. Row 1 neutral/tilt/neutral/blink; row 2 four alternating-foot waddling poses; row 3 upright/lean/peck/return; row 4 crouch/lift/peak/land. Match 16px terrain and 32px cozy game characters.

Behavior uses the existing collision/path checks with a separate small duck state machine: 2-step indoor outings, 3-step yard outings, idle/tilt/peck/hop pauses. No bark, sound, hunger, realtime or farm interactions. Movement stays local. Existing catalog/ownership and `pixel_pet_equipment.active_pet` persist purchase and one active companion (`pet_dog`, `pet_duck`, or null).
